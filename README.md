# AI for Procurement & Warehouse Auditing

A self-paced, interactive course on using AI to audit procurement, invoice and stock data across several warehouses. It is written for complete beginners and builds up step by step to advanced topics.

**Live site:** https://bireshwarchakravarty.github.io/MyAItrainer/

## What's in it

- **14 modules in 5 parts:** Foundations → Talking to AI → AI for your audit work (including spend, stock and supplier playbooks and a full month-end case study) → Reporting and automation → Going further
- **A test after every module:** 5 to 8 questions in mixed formats (single answer, select all, true/false, put in order, matching, numeric). Pass mark 70%, unlimited retakes, best score kept.
- **A hands-on assignment after every module:** tasks, written answers and questions checked against the practice data. A module counts as done when its test is passed and its assignment is complete.
- **A final assessment:** 20 questions across the course, pass mark 75%, required for the certificate.
- **Practice data pack** (`data/`): fictional cycle counts, POs, goods receipts, invoices, vendor master, transfers, stock on hand and spend lines for 7 warehouses, with problems planted on purpose. Includes an Excel workbook, CSVs, seven per-warehouse files for the Power Query exercise, and an answer key.
- **Reference pages:** my progress (gradebook), practice data, prompt library (40 prompts), quick reference, glossary, troubleshooting and sources.
- Progress is saved in each viewer's own browser.

## Hosting

GitHub Pages serves the site from branch `claude/inspiring-thompson-4xkl6t`, folder `/ (root)`. Every push to that branch updates the site within a minute or two. The `.nojekyll` file tells GitHub to serve the files as they are.

## Editing

Course source files are in `src/`, one per module. After editing, rebuild:

```bash
./build.sh
```

This produces `index.html` (the standalone site) and `dist/course.html` (body-only version used for publishing as a Claude artifact).

The practice data is generated by a seeded script, so it is the same every time. Regenerate it (and the answers the assignments check against) with:

```bash
python3 tools/make_data.py
```

Changing the script changes the data and the answers, so rerun `./build.sh` afterwards.
