Part B · Copilot inside Excel

If your company has Microsoft 365 Copilot, Excel has three AI features. Each fits a different job.

FeatureWhat it's forExample requestCaution
Copilot chat (side pane)Quick one-step help on the open sheet: formula columns, highlighting, sorting, PivotTables, charts, explanations"Add a column that flags variance over 2% and highlight those rows"Check the formula it added, not just the result
Agent ModeMulti-step builds: new summary sheets, models, dashboards, step by step"Create a sheet summarising IRA, gross variance and top 10 SKUs by warehouse, with a bar chart"Review each sheet it builds. Output consistency can vary between runs.
=COPILOT() functionClassifying or summarising text in cells=COPILOT("Classify this adjustment reason as Damage, Count error, UOM, Transfer, or Other", F2)Not for numbers or anything needing accuracy or repeatability
Microsoft's own warning

Microsoft states that the =COPILOT() function should not be used for tasks requiring accuracy or reproducibility, such as numerical calculations. It recommends native formulas (SUM, IF, XLOOKUP) for those. Use =COPILOT() for language tasks like sorting free-text reasons into categories, and spot-check its output.

Practical requirements: Copilot in Excel works best when your data is formatted as an Excel Table and the workbook is saved in OneDrive or SharePoint with AutoSave on. Features and availability vary by licence and update channel, so check with IT what you have.

Part C · Combine seven warehouse files automatically

If each warehouse sends you its own file every month, Power Query (built into Excel, under the Data tab) can stack them into one table. It isn't AI, but it is the single biggest time-saver for multi-warehouse audit work, and AI can help you set it up.

  1. Make a dedicated folder. For example Audit/2026-11/Stock files. Put only the seven warehouse files in it. Don't save your report workbook in the same folder, or it will be picked up as a data file.
  2. Get data from the folder. In a new workbook: Data → Get Data → From File → From Folder. Pick the folder.
  3. Choose "Combine & Transform". Power Query uses the first file as a sample to understand the layout. Pick the sheet or table to combine.
  4. Clean once, in the editor. Remove blank rows, set data types (numbers, dates, text for SKU codes), rename columns. Power Query keeps the source file name as a column, which you can turn into your warehouse code.
  5. Close & Load. You now have one table of all seven warehouses.
  6. Next month: refresh. Replace the files in the folder, open the workbook and click Data → Refresh All. Every cleaning step reruns automatically.
I'm combining 7 warehouse stock files in Excel Power Query (From Folder). Each file has the same columns: [list].
Problems: [e.g. WH04's file has 2 header rows / dates are text / SKU codes lose leading zeros].
Give me step-by-step clicks in the Power Query editor to fix each problem. If a step needs M code, give me the exact code and tell me where to paste it.
Why this matters

If the warehouse files use different layouts, ask each warehouse to use the same template. Show AI two different layouts and ask it to design a single template with clear column names and instructions. Standard inputs are the foundation of every later automation.

Part D · Make exceptions jump out

Three Excel features turn a big table into an exception report. AI can set up any of them if you describe what you want.

  • Conditional formatting: colour rows where variance is outside tolerance, duplicates exist, or dates are on weekends. Ask: Give me a conditional formatting formula that highlights the entire row when [Var_Pct] is beyond ±2%.
  • PivotTables: summarise by warehouse, supplier, SKU class or month in seconds. Ask Copilot: Create a PivotTable of gross variance value by warehouse and ABC class.
  • FILTER function: a live exceptions list that updates when the data changes. See the formula lab above.

Part E · When files get too big

Excel slows down beyond a few hundred thousand rows, and some analysis (statistical tests, fuzzy matching of supplier names) is awkward in formulas. Two options:

  • Upload to an AI assistant with data analysis. It writes and runs Python for you. Ask it to show the code, and keep that code for next time.
  • Python in Excel, where available in your Microsoft 365 plan, lets you run Python inside a cell. AI can write the Python for you. Treat it as a later-stage skill.

Key takeaways

  • Describe what you need in plain English and let AI write the formula. Test it on known rows.
  • Copilot chat for quick edits, Agent Mode for multi-step builds, =COPILOT() only for text.
  • Power Query combines seven warehouse files into one table that refreshes in one click.
  • Conditional formatting, PivotTables and FILTER turn data into an exception report.
