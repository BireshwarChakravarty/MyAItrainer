All invented

Rules used in the data

  • Count tolerance is ±2% per line. Variance = counted minus system (negative means stock is missing).
  • PO approval limit is $5,000 for a manager and $20,000 for a director.
  • Snapshot date for stock and open items is 31 October 2026. Dates are written YYYY-MM-DD.
  • Unit costs are per each (EA). Case_Size is the number of eaches in a case.

Quick reference

The course on one page: the checklists you'll use most often once you've finished the modules.

Writing a request (Module 4)

  • Role: who the AI should act as
  • Task: exactly what to do
  • Context: your data, rules, tolerances
  • Format: table, bullets, length
  • Checks: use only my data; say if unsure; give row counts

Before sharing data (Module 3)

  • Green: general questions, made-up or public data. Any approved tool.
  • Amber: internal data. Company-approved tool only.
  • Red: prices, bank details, personal data, NDA material. Never, unless policy allows.
  • When unsure: anonymise, or ask for the method and apply it yourself.

Checking AI output (Module 3)

  1. Tie row counts and totals to Excel
  2. Spot-check 5–10 rows by hand
  3. Ask how it got the answer
  4. Ask it to review its own answer
  5. Trace findings to system records

Clean data (Module 5)

  • One header row, no merged cells
  • One row per record, one type per column
  • Units stated in headers
  • A warehouse column
  • A data dictionary in the prompt

Audit routines (Modules 8–9)

  • P1 Monthly variance review
  • P2 Duplicate invoices
  • P3 Split POs
  • P4 Vendor master
  • P5 Risk-based counts
  • P6 Adjustment reasons
  • P7 Spend · P8 Transfers · P9 Stock age · P10 Suppliers

Writing a finding (Module 11)

  • Condition: what you found
  • Criteria: what it should be
  • Cause: why it happened
  • Effect: why it matters
  • Corrective action: who, what, by when

Troubleshooting

Common problems when using AI for data work, and what to do about them.

ProblemWhat to try
The Copilot button in Excel is missing or greyed outCopilot needs a Microsoft 365 Copilot licence, and the file saved in OneDrive or SharePoint with AutoSave on. Format the data as a table (Ctrl+T). If it's still missing, ask IT whether your licence includes it.
"I can't open that file" or the upload failsCheck the file size limit of your tool. Save as CSV instead of XLSX, remove unused sheets, or split the file. Some tools only analyse files when a data-analysis feature is switched on.
The AI analysed only part of the dataAsk for row counts per group first. If they don't match, tell it the expected total and ask it to reload the whole file using code.
Numbers are different each time I askAsk it to use code for every calculation and show the code. Better still, ask for the Excel formula and calculate it yourself.
A formula returns #NAME?The function may not exist in your Excel version (TAKE, FILTER and XLOOKUP need Microsoft 365). Tell the AI your version and ask for an alternative.
Dates are wrong or treated as textState the date format in your prompt (for example YYYY-MM-DD or DD/MM/YYYY). In Excel, use Data → Text to Columns or Power Query to convert.
Product codes lost their leading zerosTell the AI that code columns are text, not numbers. In Power Query, set the column type to Text before loading.
The AI refuses or gives a very cautious answerExplain the business context: "I'm an internal auditor reviewing our own purchase data for duplicate payments." Remove personal data that isn't needed.
The answer is genericAdd context (warehouses, tolerances, columns) and a specific format. See Module 4.
The AI states a conclusion the data can't support ("theft", "fraud")Ask "which rows support this?" and rewrite the finding to say only what the data shows.
I lost my progress in this courseProgress is saved in your browser on this device. It's lost if you clear browsing data or use a private window, and it doesn't move between devices.
